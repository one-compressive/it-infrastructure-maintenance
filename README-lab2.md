# Лабораторная работа 2

## Тема
Доработка многостраничного сайта и улучшение пользовательского интерфейса калькулятора.

## Цель работы
Закрепить навыки работы с HTML/CSS/JavaScript на практике и доработать учебный проект, созданный в предыдущей лабораторной.

## Выполненные задачи
- Сохранена структура проекта из нескольких страниц:
  - `main.html` (главная),
  - `calculator.html` (калькулятор),
  - `author.html` (об авторе).
- Развиты стили интерфейса:
  - оформление навигации и карточек с контентом;
  - стили для нескольких визуальных тем.
- Сохранена и расширена логика калькулятора:
  - обработка цифрового ввода;
  - последовательные арифметические операции;
  - дополнительные математические функции;
  - управление состоянием экрана результата.

## Использованные технологии
- HTML5
- CSS3
- JavaScript (vanilla JS)

## Структура лабораторной
- `main.html`, `main.css`
- `author.html`, `author.css`
- `calculator.html`, `calculator.css`, `calculator.js`
- `img/` - изображения и фон

## Результат
Получен более целостный учебный веб-проект с единой стилистикой страниц и интерактивным калькулятором, готовый как база для дальнейшего перехода к компонентному подходу.
