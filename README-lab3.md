# Лабораторная работа 3

## Тема
Переход от статического многостраничного сайта к компонентному одностраничному приложению (SPA) на JavaScript.

## Цель работы
Освоить компонентную организацию клиентского кода и рендеринг интерфейса через JavaScript-классы.

## Выполненные задачи
- Создано SPA-приложение с корневой точкой входа `main.js`.
- Введена страничная архитектура:
  - `pages/main/index.js` - список статей;
  - `pages/product/index.js` - карточка выбранной статьи.
- Реализованы переиспользуемые UI-компоненты:
  - `components/product-card/` - карточка статьи;
  - `components/product/` - детальный блок статьи;
  - `components/back-button/` - кнопка возврата к списку.
- Добавлена кастомная стилизация в `styles.css`:
  - единая палитра и типографика;
  - адаптивная сетка карточек;
  - оформление детальной страницы;
  - hover-эффекты для кнопок.
- Подключен Bootstrap и реализован `Popover` для кнопки "Подробнее".

## Использованные технологии
- JavaScript ES6 Modules
- HTML5
- CSS3
- Bootstrap 5

## Структура лабораторной
- `index.html`, `main.js` - инициализация приложения;
- `pages/` - логика экранов;
- `components/` - переиспользуемые UI-блоки;
- `styles.css` - кастомные стили;
- `img/` - изображения карточек.

## Запуск
Открыть `index.html` в браузере или использовать локальный статический сервер.

## Результат
Получено SPA-приложение с компонентной структурой, навигацией между списком и детальной страницей статьи, и современным адаптивным интерфейсом.
