# Лабораторная работа 1

## Тема
Разработка многостраничного сайта на HTML, CSS и JavaScript по тематике обслуживания ИТ-инфраструктуры.

## Цель работы
Освоить базовые инструменты построения пользовательских веб-интерфейсов:
- HTML-разметка;
- CSS-стилизация;
- подключение JavaScript-логики для интерактивных элементов.

## Выполненные задачи
- Создана главная страница `main.html` с описанием предметной области.
- Добавлена страница об авторе `author.html`.
- Реализована страница калькулятора `calculator.html`.
- Написана логика калькулятора в `calculator.js`:
  - базовые операции (`+`, `-`, `x`, `/`);
  - дополнительные операции (`%`, `sqrt`, `x^2`, `x!`, `+/-`, `++`, `BS`, `C`);
  - отображение результата и обработка пользовательского ввода.
- Добавлены переключатели темы и режима отображения результата.

## Использованные технологии
- HTML5
- CSS3
- JavaScript (vanilla JS)

## Структура лабораторной
- `main.html`, `main.css` - главная страница;
- `author.html`, `author.css` - страница автора;
- `calculator.html`, `calculator.css`, `calculator.js` - веб-калькулятор;
- `img/`, `fonts/` - графические и шрифтовые ресурсы.

## Результат
Собран работоспособный многостраничный веб-проект с навигацией и интерактивным калькулятором, демонстрирующий базовые навыки верстки и программирования интерфейса.
